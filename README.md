## 🌐 English Documentation

### Features
* **Batch Conversion:** Convert single or multiple video files to MP3 simultaneously.
* **Custom Bitrates:** Choose preferred audio quality (320k, 256k, 192k, 128k).
* **Wide Format Support:** Works with MP4, AVI, MKV, MOV, WEBM, FLV, WMV, 3GP, and more.
* **Modern GUI:** High-DPI aware, clean interface with custom Tkinter styling.
* **Real-Time Progress:** Track conversion percentage and status per file in real time.
* **Metadata Preservation:** Automatically retains video metadata during conversion.
* **Safe Cancellation:** Halt operations instantly without leaving background FFmpeg processes running.

### Requirements
Ensure the following files are in the **same directory**:
1. `video_to_mp3.pyw` (or the compiled `.exe`)
2. `ffmpeg.exe`
